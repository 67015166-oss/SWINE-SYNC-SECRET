# SWINE SYNC — ก้อนความลับ

ที่เก็บ **กุญแจและรหัสผ่านของระบบ SWINE SYNC** สำหรับส่งมอบให้บริษัท
แยกออกมาจากรีโปโค้ด (`SWINE SYNC`) โดยตั้งใจ เพราะคนละคนควรเข้าถึงได้

> ★★ **ระบบนี้ขึ้นใหม่ไม่ได้ถ้าของในรีโปนี้หาย** — โค้ดอยู่ใน git แต่รหัสและกุญแจไม่ได้อยู่
> มีโค้ดอย่างเดียวได้ระบบที่ขึ้นมาแล้วต่อฐานไม่ได้ ส่งไลน์ไม่ได้ และไม่มีใครล็อกอินเข้าไปได้

---

## ★★ กฎสองข้อที่ห้ามละเมิด

**1. ไม่มีค่าจริงนอนเป็นข้อความเปล่าในรีโปนี้เลยสักตัว**
ค่าจริงอยู่ใน **ก้อนเดียวที่เข้ารหัส AES-256 แล้ว** (`ก้อนความลับ/*.tar.gz.enc`) เท่านั้น
ที่เหลือในรีโปนี้เป็น **ชื่อค่า คำอธิบาย และวิธีทำ** ซึ่งปลอดภัยที่จะอยู่ใน git

**2. ตัวก้อนกับรหัสผ่านต้องเดินคนละทาง**
รหัสผ่านที่เปิดก้อน **ห้ามอยู่ในรีโปนี้ ห้ามส่งทางเดียวกับที่ส่งลิงก์รีโปนี้**
➜ เก็บในโปรแกรมจัดการรหัสผ่านของบริษัท หรือใส่ซองปิดผนึกส่งตัวต่อตัว
ถ้าช่องทางเดียวรั่วแล้วได้ทั้งก้อนและกุญแจพร้อมกัน **เท่ากับไม่ได้เข้ารหัสเลย**

★ และต้องมีคนรู้ที่เก็บรหัสผ่าน **อย่างน้อยสองคน** ไม่งั้นก็แค่ย้ายปัญหา
"มีคนเดียวที่เปิดได้" จากเครื่องของผู้พัฒนาเดิมมาไว้ที่คนใหม่เฉย ๆ

## ★★ ใส่ค่าจริงลงรีโปนี้ — คำสั่งเดียวจบ

```bash
BOX=root@<ที่อยู่ของกล่อง> sh ops/ship.sh
```

ทำให้ครบสี่ขั้น — ตรวจต้นทาง → ปิดผนึกใบใหม่ → **เปิดดูว่าเปิดได้จริง** → commit + push
ถามรหัสผ่าน 3 ครั้ง (สองครั้งแรกตอนปิดผนึก · ครั้งที่สามตอนเปิดตรวจ)

★ **ขั้นเปิดตรวจข้ามไม่ได้** — เปิดไม่ได้หรือไฟล์ไม่ครบ 6 **สคริปต์หยุดเองไม่ push**
"สำรองที่ไม่เคยลองเปิด = ยังไม่รู้ว่าสำรองได้หรือเปล่า"

## สภาพของรีโปนี้ตอนส่งมอบ

```bash
sh ops/status.sh
```

ตอบว่ามีก้อนอยู่ไหม · ใบไหนใหม่สุด · และ **ก้อนนั้นเก่ากว่าไฟล์ต้นทางหรือเปล่า**

★★ **ตรวจข้อสุดท้ายให้เป็นนิสัย** — ก้อนที่เก่ากว่า `.env` ปัจจุบันคือก้อนที่
**กู้แล้วได้ระบบที่ขาดค่า** โดยไม่มีอะไรฟ้อง เกิดมาแล้วจริงสองครั้ง
(8 ต.ค. 2569 ขาดบัญชีผู้ดูแล · 28 ต.ค. 2569 ขาดกุญแจของตู้กลาง)

## ของที่ไม่ได้อยู่ในรีโปนี้

| ไม่อยู่ | อยู่ที่ไหน |
| --- | --- |
| **รหัสผ่านที่เปิดก้อน** | คนละช่องทาง ตามกฎข้อ 2 |
| **ไฟล์สำรองฐานข้อมูล** | แยกอีกที่ · ★ **ห้ามวางคู่กับก้อนนี้** เพราะเหตุผลที่เข้ารหัสคือ "ได้ไฟล์สำรองไปอย่างเดียวต้องใช้ไม่ได้" |
| โค้ดและเอกสารส่งมอบ | รีโป `SWINE SYNC` |
| รหัสผ่านผู้ใช้แดชบอร์ด | ไม่มีใครมี — ในฐานเก็บเป็นแฮช · ลืมแล้วให้ผู้ดูแลระบบตั้งใหม่ |
