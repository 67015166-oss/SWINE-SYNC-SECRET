# แบบไฟล์เปล่า — กรอกค่าใหม่ตั้งแต่ต้น

ใช้เมื่อ **ไม่มีก้อนให้กู้** หรือจะตั้งระบบใหม่ด้วยค่าชุดใหม่ทั้งหมด
ทุกไฟล์ในโฟลเดอร์นี้ **มีแต่ชื่อคีย์กับคำอธิบาย ไม่มีค่าจริง**

| ไฟล์ | คัดลอกไปเป็น |
| --- | --- |
| `env-กล่อง.example` | `/home/dev/swine/app/.env` บนกล่อง |
| `env-คลังพยากรณ์.example` | `weather/.env` ในรีโปโค้ด |
| — | `.env` ที่รากรีโปโค้ด ➜ ใช้ **`.env.example` ในรีโปโค้ด** ซึ่งมีคำอธิบายครบทุกบรรทัด |

★ เติมคีย์ใหม่ที่นี่ด้วยทุกครั้งที่เพิ่มค่าในระบบ — กู้ตามไฟล์ที่ขาดคีย์
แล้วจะได้ระบบที่ขาดค่า **โดยไม่มีอะไรฟ้อง** (เกิดมาแล้วสองครั้ง)
